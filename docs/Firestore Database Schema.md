# Firestore Database Schema

Nudge uses Cloud Firestore with two top-level collections: `users` and `courses`.

## Users

**Path:** `users/{userId}`

| Field | Type | Description |
|---|---|---|
| name | String | User's name |
| email | String | User's email |
| createdAt | Timestamp | Account creation time |

The document ID is the user's Firebase Authentication UID.

## Courses

**Path:** `courses/{courseId}`

| Field | Type | Description |
|---|---|---|
| name | String | Course name |
| description | String | Course description |
| creatorId | String | UID of the original creator |
| joinCode | String | Code used to join the course |
| createdAt | Timestamp | Course creation time |

Course IDs are generated by Firestore.

## Course Memberships

**Path:** `courses/{courseId}/members/{userId}`

| Field | Type | Description |
|---|---|---|
| userId | String | User's Firebase Authentication UID |
| role | String | Role within the course |
| joinedAt | Timestamp | Time the user joined |

Membership document IDs match the user's Firebase Authentication UID.
Course memberships are stored in a members subcollection under each course. Each membership tracks a user's role within that course.

### Roles

- `creator`: Full course management permissions.
- `ta`: Can manage office-hour sessions and queues.
- `student`: Can join sessions and participate in queues.

Roles are course-specific. Each course has one creator, who is automatically assigned the `creator` role.
Defined enums for these in Models/CourseRole

## Database Structure

```text
users/                              # Collection
    {userId}/                       # Document (Firebase Auth UID)
        name
        email
        createdAt

courses/                            # Collection
    {courseId}/                     # Document (Firestore-generated ID)
        name
        description
        creatorId
        joinCode
        createdAt

        members/                    # Subcollection
            {userId}/               # Document (Firebase Auth UID)
                userId
                role
                joinedAt
```

Each course has its own `members` subcollection. A user can belong to multiple courses with different roles in each.
